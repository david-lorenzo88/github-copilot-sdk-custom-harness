# Valuation metrics

| Metric | Definition |
|---|---|
| Market value | shares × current price |
| Cost | shares × cost_basis |
| Unrealized P/L | market value − cost |
| Unrealized P/L % | unrealized P/L ÷ cost |
| Weight | market value ÷ total market value |
| Holding period | days since purchase_date |

Long-term holdings: more than 365 days (relevant for taxes in many countries; not tax advice).
